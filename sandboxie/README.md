# Sandboxie: Ilocano-Based Tutorial System

This is a modern web-based educational application designed for BSIT and Senior High ICT students to learn how to handle malware using Windows Sandbox. The tutorials are written in Ilocano.

## Features
- **Progress Tracking**: Users can mark their tutorial modules as complete, and the progress is saved locally using browser `localStorage`.
- **Ilocano Content**: Authentic step-by-step instructions for each module.
- **Responsive UI**: Built with Bootstrap 5.

## Tech Stack
- Frontend: React (Vite)
- UI Library: Bootstrap 5
- State Management: `localStorage`

## Setup Instructions

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Visit the local server address (usually `http://localhost:5173`) to view the application.
